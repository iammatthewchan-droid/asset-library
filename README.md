# DeepStack Asset Library — 20261107-r175

82 visible entries: 80 bundled original downloads and 2 official font-reference links.

## End users
Open https://iammatthewchan-droid.github.io/asset-library/ . The main page offers browsing, previews and downloads. This static edition has no upload, removal or editor API.

## Reuse by Elton
All HTML, CSS, JavaScript, SVG, preview artwork and bundled downloads are supplied as ordinary editable files. No proprietary build service or owner computer is required. Copy this directory into your own repository and adapt the interface for another website. Brand artwork and third-party/font rights remain with their holders; possession of the code does not transfer those trademarks.

## Run locally
From the parent directory, name this folder `asset-library`, then run `python3 -m http.server 8000`. Open http://localhost:8000/asset-library/ . Do not open HTML directly as file:// because browser fetch requires HTTP.

## Deploy
GitHub Pages: deploy this folder at /asset-library/ (current setting). Vercel: import this folder as an Other/static project; vercel.json maps /asset-library/ URLs to the root. No package install or compilation is required; dependencies are vendored. A clean copy of the source is the build output.

## Update and rollback
Edit code/assets and the three data catalogs together, validate release-manifest.json hashes, commit and publish. Keep the previous Git commit for rollback. The local authenticated Builder is separate from this public static edition.

## Scope
The manifest is the common inventory for website, Hub-ready entries and ZIP. Editable originals are included when the library stores them (.ai/.psd/etc.); a PNG is not represented as a native design master. The two font archives are official external links. Team Hub import and regional network results are separately recorded in the handoff.
